# 産休育休マネープラン 公開手順

このフォルダの6つのファイルをGitHub Pages（無料）に置くと、誰でもURLから開けるWebアプリになります。iPhoneでホーム画面に追加すると、アドレスバーのないアプリとして使え、電波がなくても開けます。

## 入っているファイル

| ファイル | 役割 |
| --- | --- |
| index.html | アプリ本体 |
| manifest.webmanifest | アプリ名・アイコンなど、ホーム画面に追加したときの設定 |
| sw.js | 電波がなくても開けるようにする仕組み |
| icon-192.png / icon-512.png | アプリのアイコン |
| apple-touch-icon.png | iPhoneのホーム画面用アイコン |

## 1. GitHubのアカウントを作る

1. https://github.com を開き「Sign up」からアカウントを作ります（無料）。
2. ユーザー名はURLの一部になります（例：`https://ユーザー名.github.io/...`）。薬局名など、公開しても困らない名前にしてください。

## 2. 置き場所（リポジトリ）を作る

1. ログイン後、右上の「＋」→「New repository」を選びます。
2. Repository name に `leave-money` など英数字の名前を入れます。
3. 「Public」を選び、「Create repository」を押します。

## 3. ファイルをアップロードする

1. 作ったリポジトリの画面で「uploading an existing file」をクリックします。
2. このフォルダの6つのファイルをまとめてドラッグ＆ドロップします（README.mdは入れても入れなくても構いません）。
3. 下の「Commit changes」を押します。

## 4. 公開する

1. リポジトリの「Settings」→ 左メニューの「Pages」を開きます。
2. 「Branch」で `main` と `/ (root)` を選び、「Save」を押します。
3. 1〜2分待つと、画面上部に公開URL（`https://ユーザー名.github.io/leave-money/`）が表示されます。

## 5. iPhoneのホーム画面に追加する

1. iPhoneのSafariで公開URLを開きます。
2. 下の共有ボタン（□に↑）→「ホーム画面に追加」を選びます。
3. ホーム画面の「育休マネー」アイコンから起動できます。

## アプリを更新したいとき

1. 新しい `index.html` を同じ手順でアップロードし直します（同じ名前のファイルは上書きされます）。
2. `sw.js` の中の `VERSION = "v1"` を `"v2"` のように1つ上げてアップロードすると、使っている人のiPhoneにも確実に新しい版が届きます。

## 気をつけること

- 入力した内容はそれぞれのスマホの中だけに保存され、サーバーには送られません。患者さんやスタッフの情報がGitHubに残ることはありません。
- 給付金の上限額は毎年8月1日に変わります。毎年8月以降に、`index.html` の中の `dailyMax:16540,dailyMin:3203` の数字を新しい額に更新してください（Claudeに頼めば更新版を作れます）。
- 計算は概算です。人に配る場合は、画面下の「この計算の前提」を必ず読んでもらうようにしてください。
